# คอร์สติวสอบ IC License (ผู้แนะนำการลงทุนตราสารทั่วไป — IC Plain)
## วิเคราะห์แบบฝึกหัด + แผนเรียนรู้ด้วยตัวเอง 4 สัปดาห์

---

## ส่วนที่ 1: วิเคราะห์แบบฝึกหัดทั้ง 5 ชุด

| ชุด | หัวข้อ | จำนวนข้อ | หมวดข้อสอบจริง | ลักษณะข้อสอบ |
|---|---|---|---|---|
| 1 | จรรยาบรรณ / กฎระเบียบ / การแนะนำที่เหมาะสม | 33 | หมวด 2 | ความเข้าใจหลักการ + จำเกณฑ์ตัวเลข |
| 2 | คำนวณ (ผลตอบแทน ความเสี่ยง ประเมินมูลค่า NAV) | 39 | หมวด 1 + 3 | ใช้สูตร ~15 สูตร |
| 3 | กองทุนรวม | 27 | หมวด 3 | ความเข้าใจประเภทกองทุน + คำนวณ NAV/TER |

| 5 | ตราสารหนี้ | 27 | หมวด 3 | ความเข้าใจ + ดูเรชัน + คำนวณมูลค่า/current yield |

### ข้อสังเกตสำคัญจากการวิเคราะห์

1. **ข้อคำนวณออกซ้ำข้ามชุด** — ข้อเดียวกันปรากฏทั้งชุดคำนวณและชุดเนื้อหา เช่น มูลค่าเวลาวอร์แรนท์, กำไร/ขาดทุนวอร์แรนท์, มูลค่าหุ้นกู้ (958.42), NAV ต่อหน่วย, ผลตอบแทนกองทุน (9.21%), TER
   → **นี่คือ "ข้อสอบยอดนิยม" ที่ต้องทำได้ 100%**
2. **โจทย์คำนวณมีแพทเทิร์นตายตัว** ประมาณ 12 แพทเทิร์น (ดูสรุปสูตรส่วนที่ 4) — ฝึกซ้ำจนทำได้ใน 1–2 นาที/ข้อ
3. **จรรยาบรรณเป็นหมวดชี้ขาด** — ข้อสอบจริงกำหนดว่าต้องผ่านทั้งคะแนนรวม **และ** หมวดจรรยาบรรณแยกต่างหาก (เกณฑ์ ~70%) ห้ามทิ้งหมวดนี้เด็ดขาด
4. **ข้อ "ตัวเลือกใด I II III"** มีสัดส่วนสูงมาก — เทคนิคคือตัดข้อที่รู้ว่าผิดชัด ๆ ก่อน มักเหลือตัวเลือกเดียว
5. **ตัวเลขเกณฑ์ที่ต้องจำแม่น** (ออกสอบตรง ๆ):
   - ผู้ลงทุนเปราะบาง: อายุ ≥ 60 ปี + ไม่มีความรู้/ประสบการณ์
   - Underwriter ห้ามชักชวน/แนะนำ: 15 วันทำการก่อนเสนอขาย → วันปิดการขาย; เปิดเผยส่วนได้เสียในบทวิเคราะห์: วันปิดการขาย → 30 วัน
   - Margin: เรียกหลักประกันเพิ่มเมื่อ < 35%, บังคับขายเมื่อ < 25%
   - Strategic shareholders: ห้ามขายหุ้น 55% เป็นเวลา 1 ปี
   - Circuit breaker ขั้น 1: ดัชนีลง 8% หยุด 30 นาที (ขั้น 2: 15%, ขั้น 3: 20%)
   - ทุนชำระแล้วเข้าจดทะเบียน SET ≥ 300 ล้านบาท
   - Investment grade: BBB- (TRIS/S&P) หรือ Baa3 (Moody's) ขึ้นไป
   - กองทุนอสังหาฯ/REIT จ่ายปันผล ≥ 90% ของกำไรสุทธิ
   - ชำระราคาตราสารหนี้/หุ้น: T+2

### โครงสร้างข้อสอบจริง IC Plain (P1)
- ข้อสอบปรนัย ~100 ข้อ / เวลาสอบประมาณ 2 ชั่วโมงครึ่ง
- เกณฑ์ผ่าน: คะแนนรวม ≥ 70% **และ** หมวดจรรยาบรรณ ≥ 70%
- ครอบคลุม 3 หมวด: (1) ความรู้พื้นฐานการเงินการลงทุน (2) กฎระเบียบ จรรยาบรรณ และการแนะนำที่เหมาะสม (3) ความรู้เกี่ยวกับผลิตภัณฑ์ (ตราสารทุน ตราสารหนี้ กองทุนรวม)
- *หมายเหตุ: ตรวจสอบจำนวนข้อ/เวลา/เกณฑ์ล่าสุดกับ ATI หรือ SET ก่อนสมัครสอบอีกครั้ง*

## ส่วนที่ 3: สมุดข้อผิด (วิธีใช้)

ทุกครั้งที่ทำผิด ให้จด 3 บรรทัด:
1. โจทย์ถามอะไร (สรุปสั้น)
2. ทำไมถึงผิด (จำสูตรผิด / อ่านโจทย์พลาด / ไม่รู้เนื้อหา / หลงกับดัก "ไม่ถูกต้อง")
3. หลักที่ถูกต้องคืออะไร

ทวนสมุดนี้ทุก 3 วัน — ข้อที่ผิดซ้ำ 2 รอบ = จุดอ่อนจริง ต้องกลับไปอ่านเนื้อหา

## ส่วนที่ 4: สรุปสูตรที่ต้องจำ (Formula Sheet)

### ผลตอบแทนและมูลค่าเงิน
| สูตร | รูปแบบ |
|---|---|
| ผลตอบแทนงวดเดียว (HPR) | (ราคาขาย − ราคาซื้อ + ปันผล) ÷ ราคาซื้อ |
| ผลตอบแทนที่แท้จริง (โดยประมาณ) | ผลตอบแทน − เงินเฟ้อ |
| มูลค่าอนาคต | FV = PV × (1+r)ⁿ |
| EAR | (1 + APR/m)ᵐ − 1 (ทบต้นบ่อยขึ้น → EAR สูงขึ้น, APR คงที่) |
| ค่าเฉลี่ยเรขาคณิต | GM = ⁿ√[(1+r₁)(1+r₂)...] − 1 |
| ผลตอบแทนคาดหวัง | E(R) = Σ(ความน่าจะเป็น × ผลตอบแทน) |
| ค่าสัมประสิทธิ์ความแปรผัน | CV = SD ÷ ผลตอบแทน (**ยิ่งต่ำยิ่งน่าลงทุน**) |
| ผลตอบแทนพอร์ต | Rp = Σ(น้ำหนัก × ผลตอบแทน) |

### CAPM และการวัดผล
| สูตร | รูปแบบ |
|---|---|
| CAPM (ผลตอบแทนที่ต้องการ) | k = Rf + β(Rm − Rf) |
| ส่วนชดเชยความเสี่ยง | β(Rm − Rf) |
| ตัดสินใจ | ผลตอบแทนคาดหวัง > k → **Underpriced ซื้อ** / < k → **Overpriced ขาย** |
| Sharpe | ใช้ความเสี่ยงรวม (SD) — unsystematic เพิ่ม → Sharpe ลด |
| Treynor | ใช้ β (systematic เท่านั้น) — unsystematic เปลี่ยน → Treynor คงที่ |
| Jensen's alpha | ผลตอบแทนจริง เทียบกับ CAPM |

### ประเมินมูลค่าหุ้น
| สูตร | รูปแบบ |
|---|---|
| DDM (Gordon) | P = D₁ ÷ (k − g) โดย **D₁ = D₀ × (1+g)** ← จุดที่คนพลาดบ่อยสุด |
| PER | ราคาเหมาะสม = PER × EPS (EPS = กำไรสุทธิ ÷ จำนวนหุ้น) |
| PBV | ราคาเหมาะสม = PBV × BV (BV = ส่วนผู้ถือหุ้น ÷ จำนวนหุ้น) |
| ตัดสินใจ | ราคาตลาด < ราคาเหมาะสม → **Underpriced ซื้อ** |
| ROE | กำไรสุทธิ ÷ ส่วนของผู้ถือหุ้น |
| D/E | หนี้สิน ÷ ส่วนของผู้ถือหุ้น (**ต่ำ = ความเสี่ยงการเงินต่ำ**) |

### วอร์แรนท์
| สูตร | รูปแบบ |
|---|---|
| มูลค่าที่แท้จริง (call) | max(ราคาหุ้น − ราคาใช้สิทธิ, 0) |
| มูลค่าเวลา | ราคาวอร์แรนท์ − มูลค่าที่แท้จริง |
| กำไร/ขาดทุน | Δราคาหุ้น × ค่าความไว (delta) × จำนวนหน่วย |
| ราคาวอร์แรนท์เพิ่มเมื่อ | ราคาหุ้นอ้างอิง↑, ความผันผวน↑, อายุคงเหลือ↑, ดอกเบี้ย↑, ราคาใช้สิทธิ↓, ปันผล↓ |

### ตราสารหนี้
| สูตร | รูปแบบ |
|---|---|
| มูลค่าหุ้นกู้ (จ่ายครึ่งปี) | PV ของกระแสเงินสด: ดอกเบี้ย/งวด = คูปอง÷2, อัตราคิดลด/งวด = k÷2, จำนวนงวด = ปี×2 |
| Zero coupon | P = Par ÷ (1 + k/2)^(ปี×2) |
| Current yield | ดอกเบี้ยต่อปี ÷ ราคาตลาด |
| คูปอง vs k | คูปอง > k → **Premium** / คูปอง < k → **Discount** / เท่ากัน → Par |
| ดูเรชันสูงเมื่อ | อายุคงเหลือยาว, คูปองต่ำ, YTM ต่ำ → ราคาอ่อนไหวต่อดอกเบี้ยมาก |

### กองทุนรวม
| สูตร | รูปแบบ |
|---|---|
| NAV ต่อหน่วย | (ทรัพย์สินตามราคาตลาด + รายได้ค้างรับ + เงินสด − หนี้สิน − ค่าใช้จ่ายค้างจ่าย) ÷ จำนวนหน่วย |
| ผลตอบแทนผู้ลงทุน | (ราคารับซื้อคืนตอนขาย − ราคาขายตอนซื้อ + ปันผล) ÷ ราคาขายตอนซื้อ — **ซื้อที่ offer ขายที่ bid** |
| TER (เก็บจากกองทุน) | การจัดการ + ผู้ดูแลผลประโยชน์ + นายทะเบียน + ค่าใช้จ่ายอื่น (**ใช้อัตราปัจจุบัน ไม่ใช่เพดาน; ไม่รวมค่าธรรมเนียมขาย/รับซื้อคืน**) |
| ค่าใช้จ่ายเก็บจากผู้ลงทุน | ค่าธรรมเนียมขาย + ค่าธรรมเนียมรับซื้อคืน (ตามระยะเวลาถือ) |

## ส่วนที่ 5: เทคนิคทำข้อสอบ

1. **ขีดคำว่า "ไม่" ทุกครั้ง** — กับดักอันดับ 1 คือโจทย์ถาม "ตัวเลือกใด**ไม่**ถูกต้อง" แล้วผู้สอบเลือกข้อที่ถูก
2. **ข้อ I II III ใช้วิธีตัด** — หาข้อที่มั่นใจว่าผิด 1 ข้อ มักตัดตัวเลือกได้ 2 ตัวทันที
3. **ข้อคำนวณ ทำเลขกลม ๆ ก่อน** — ตัวเลือกมักห่างกันพอที่การประมาณจะตอบได้ เช่น real return ≈ nominal − inflation
4. **จำ "คู่ตรงข้าม" เป็นชุด**:
   - ความสามารถรับความเสี่ยง (ability: อายุ รายได้ หนี้สิน ภาระ) vs ความเต็มใจ (willingness: ทัศนคติ พฤติกรรม)
   - Sharpe (ความเสี่ยงรวม) vs Treynor (เบต้า)
   - Callable (สิทธิผู้ออก, ดอกเบี้ยสูงกว่าปกติ, ใช้สิทธิเมื่อดอกเบี้ยลด) vs Puttable (สิทธิผู้ถือ, ดอกเบี้ยต่ำกว่าปกติ, ใช้สิทธิเมื่อดอกเบี้ยขึ้น)
   - Freehold (มีกรรมสิทธิ์ มีมูลค่าคงเหลือ) vs Leasehold (สิทธิเช่า มูลค่าลดจนเป็น 0)
   - IC (แนะนำได้ วางแผนไม่ได้) vs IP (แนะนำได้ + วางแผนได้)
5. **หมวดจรรยาบรรณ ให้คิดจากหลัก 3 ข้อ**: ซื่อสัตย์ต่อลูกค้า / ไม่ตัดสินใจแทน–ไม่ใช้บัญชีผู้อื่น / ผลประโยชน์ลูกค้ามาก่อนเสมอ — ข้อที่ขัดหลักใดหลักหนึ่งคือ "ผิด" แม้จะอ้างว่า "ลูกค้ายินยอม" หรือ "เพื่อไม่ให้ลูกค้าเสียโอกาส"
6. **บริหารเวลา**: ข้อความเข้าใจ ≤ 1 นาที, ข้อคำนวณ ≤ 2 นาที, ข้อไหนเกิน 3 นาทีให้ข้ามแล้วกลับมา
